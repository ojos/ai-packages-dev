# docs カタログ

このファイルは `docs/` 配下のドキュメント一覧と用途を示す索引です。

## 収録ルール

- `docs/` 配下の追跡対象ファイルを全件列挙する。
- ローカル除外（`.git/info/exclude` 等）でリポジトリに含まれないファイルは列挙しない。
- ファイル追加・削除・改名時は、このファイルを同一コミットで更新する。
