# Web Modernization (Modern Web Guidance) Task Playbook

## 目的

- Modern Web Guidance の推奨を、既存Web実装へ安全に適用する。

## 入力

- 対象UI/機能の要件。
- 既存コードとブラウザサポート方針。
- パフォーマンスとアクセシビリティ要件。

## 手順

1. 対象機能を分類する（UI更新 / パフォーマンス改善 / セキュリティ強化）。
2. 外部推奨の適用可否を事前評価する（既存仕様との衝突、サポート対象、運用コスト）。
3. 小さな変更単位で実装する。
4. 実装後に影響指標を測定する（例: LCP/INP、a11y、既存フロー回帰）。
5. 指標悪化や回帰があればロールバックする。

## 出力

- 適用差分。
- 測定結果。
- 採用/保留/不採用の判定と理由。

## 注意事項

- 外部推奨をそのまま全面適用しない。
- 既存要件と矛盾する提案は保留または不採用とする。
- セキュリティ・認証系の変更は必ず段階適用にする。
